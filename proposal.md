# The name of the Project / Repository
Impact - RPG map and text game with some UI elements maybe.
StoneKnight - The RPG text scroller



# General Concept
A movement game where you type "south" or "north" to move in the map.
There will be many interactive characters and items in the game.
There will also be a fighting system to fight enemies.
One of the main ideas of this game is a boss fight which the character has to beat.
There will also be a backpack system where the character can store items.
The player can talk with other characters throughout the map.


# Story Line 
Your village is under attack from monsters spawning at night. Nobody knows why the monsters spawn. You decided to venture out of the village and catch a glimpse out there is a great monster creating smaller monster. You must level up and defeat the great monster to save your village!



# Theme
Old time medieval theme with swords, bows, dragons, spells, and trolls 
RPG text based game


# Target user
Made for teenagers-adult who like fantasy and adventure
